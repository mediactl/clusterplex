{{ include "cluster-plex.fullname" . }} is installed.

Clients connect to the {{ include "cluster-plex.fullname" . }} Service, a LoadBalancer in front of every
Plex pod:

    kubectl get svc -n {{ .Release.Namespace }} {{ include "cluster-plex.fullname" . }}

It pins each client to one pod by its address (sessionAffinity: ClientIP, for
{{ .Values.service.sessionAffinityTimeoutSeconds }}s), because a transcode's chunks live only on the pod that wrote
them, and keeps that address the client's own with externalTrafficPolicy:
Local, which this chart enforces. Clients behind one NAT share a pod.
{{- if .Values.plex.externalURL }}

Plex advertises {{ .Values.plex.externalURL }} to clients. It has to stay live: a
stale address works until a client signs in, then fails on the way back.
{{- else if not .Values.proxy.enabled }}

Plex advertises that Service's LoadBalancer address, which the manager reads
before every start; until the load balancer assigns one, Plex keeps
advertising what it did before. Set plex.externalURL only for an address the
cluster cannot see, such as a DNS name with a certificate in front.
{{- end }}
{{- if .Values.proxy.enabled }}

The media proxy tier is on: {{ include "cluster-plex.fullname" . }}-proxy serves direct-play bytes from the
shared library. Throughput scales with the nodes running it, not replicas:
its pods are spread one per node and stay Pending beyond the node count, and
your router must install more than one next hop for its address (on
FRR-based gear, raise maximum-paths).
{{- if not .Values.plex.externalURL }}

WARNING: plex.externalURL is unset, so Plex advertises {{ include "cluster-plex.fullname" . }}, not the
proxy, and clients that follow the advertisement never reach it. Set it to the
proxy's hostname.
{{- end }}
{{- if not .Values.proxy.tls.secretName }}

WARNING: proxy.tls.secretName is unset, so the proxy speaks plain HTTP. Plex
clients prefer a secure connection and some will decline a server without one.
{{- end }}
{{- end }}
{{- if not .Values.plex.machineIdentifier }}

plex.machineIdentifier is unset, so Plex will generate an identity on first
start. Pin it if you want a rebuilt cluster to keep the identity clients
already know. Setting it on a server that already has one changes it.
{{- end }}
